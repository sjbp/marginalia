# Changelog

## 0.2.2

- `md` now retires a running copy of Marginalia that is older or lives elsewhere (for example the instance you had open before dragging a new version to Applications) before opening your file, so you always get the installed version.
- `make install` quits the running app before replacing it.

## 0.2.1

- README rewritten: why Marginalia, what it is good at, how to use it, in one screen.
- No app changes since 0.2.0.

## 0.2.0

- Title bar has an opaque, on-palette band; a hairline appears once content scrolls under it.
- New brand mark and app icon: a text column with a note in the margin. Generated by `Scripts/make-icon.py`, drawn in code for the empty state.
- Format bar stays above comment cards when they overlap.
- Selection repaints live while dragging.
- Typing no longer moves tables, images, or comment cards: restyling is incremental, overlays are reused, and floating views are placed from real layout. Covered by `make overlay-test`.
- Geist and Geist Mono are the default theme, with the larger heading scale.
- Rendered text by default with a Text | Markdown toggle; threaded comments; format bar on selection; click to toggle checkboxes; paste a URL over a selection to link.
- `make publish` runs the whole release cycle. `ARCHITECTURE.md` and `RELEASING.md` added.

## 0.1.0

- First shareable build.
